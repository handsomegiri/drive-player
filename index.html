Settings

One-time setup (easiest on a phone or computer):
  1. Open console.cloud.google.com and create a project
  2. APIs & Services → Library → enable Google Drive API
  3. APIs & Services → Credentials → Create credentials → API key
In Google Drive, share the folder as "Anyone with the link". Subfolders show up automatically.
App version:
Plays MP4 / MOV / M4V (H.264). MKV, AVI and WMV files aren't supported by Safari on iPad, so convert them to MP4 first.
